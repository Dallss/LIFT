#  LIFT

#### Lightwieght Interface For Tasks

### Recent Updates:

- Ive decided to turn this into a menu bar utility (`NSStatusItem`) with no main app window.
- First release is postponed to May 8, 2026 as I'll be taking my time on learning industry design patterns.

### Menu Bar App Behavior

- The app runs as a menu bar utility (`NSStatusItem`) with no main app window.
- Left-clicking the menu bar icon toggles a floating task panel.
- Option-clicking or Control-clicking the menu bar icon opens a dropdown menu with `Quit`.
- The floating panel uses a larger default size and enforces a minimum size for readability.
